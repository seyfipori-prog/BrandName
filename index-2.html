مهم: این نسخه فقط یک فایل HTML است و مستقیم از مرورگر به Backblaze وصل می‌شود. کلیدها فقط در حافظهٔ محلی همین مرورگر ذخیره می‌شوند، نه داخل مخزن GitHub؛ اما هرکس به این مرورگر و پروفایلش دسترسی داشته باشد می‌تواند از آن‌ها استفاده کند. برای استفادهٔ شخصی، یک Application Key محدود به همین باکت بساز. این نسخه بک‌اند، حساب‌های کاربری، نشست امن و صف بررسی ادمین نسخهٔ Worker را ندارد.

آپلود فایل

فایل‌ها مستقیم به Backblaze B2 ارسال می‌شوند. حداکثر اندازهٔ هر فایل در این ابزار ۵ گیگابایت است. محدودیت روزانهٔ ۹ گیگابایت فقط در همین مرورگر محاسبه می‌شود و محدودیت سراسری/امنیتی نیست.

تنظیم اتصال Backblaze B2

این اطلاعات در localStorage همین مرورگر ذخیره می‌شوند. برای انتشار عمومی GitHub Pages نیازی نیست کلیدها را داخل سورس قرار بدهی.

تنظیم CORS در Backblaze

در کنسول Backblaze، باکت را باز کن و در تنظیمات CORS، مبدأ دقیق GitHub Pages خودت را مجاز کن. روش‌های لازم: GET، PUT، DELETE و HEAD. در صورت امکان مبدأ را به دامنهٔ GitHub Pages خودت محدود کن. بدون CORS، مرورگر درخواست‌ها را مسدود می‌کند حتی اگر کلید درست باشد.

Application Key باید به همین باکت محدود باشد و دسترسی‌های List/Read/Write/Delete را فقط در صورت نیاز داشته باشد. هرگز Master Application Key را در سایت نگذار.
